# data_graphs_visual

A Streamlit dashboard for exploring a CSV file. Upload a CSV from the sidebar to see a preview, row, column, missing value and duplicate counts, then pick one of ten charts: histogram, box plot, scatter, line, bar, pie, violin, area, correlation heatmap or pair plot.

## Run it

```
git clone https://github.com/victorisaacchinta-eng/data_graphs_visual.git
cd data_graphs_visual
pip install streamlit pandas numpy plotly seaborn matplotlib
streamlit run app.py
```
